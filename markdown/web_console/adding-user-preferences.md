# Adding user preferences {id="adding-user-preferences"}

{%- set context = "adding-user-preferences" %}

You can change the default preferences for your profile to meet your requirements. You can set your default project, topology view (graph or list), editing medium (form or YAML), language preferences, and resource type. {._abstract}

The changes made to the user preferences are automatically saved.
