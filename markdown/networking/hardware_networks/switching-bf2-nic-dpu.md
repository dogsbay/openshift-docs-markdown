# Switching Bluefield-2 from DPU to NIC {id="switching-bf2-nic-dpu"}
{% include "./_attributes/common-attributes.md" %}
{%- set context = "switching-bf2-nic-dpu" %}

You can switch the Bluefield-2 network device from data processing unit (DPU) mode to network interface controller (NIC) mode.

Before you perform any tasks in the following documentation, ensure that you [installed the SR-IOV Network Operator](/networking/networking_operators/sr-iov-operator/installing-sriov-operator#installing-sriov-operator).
