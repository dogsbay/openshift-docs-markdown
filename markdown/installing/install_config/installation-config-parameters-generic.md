# Installation configuration parameters {id="installation-config-parameters-generic"}
{%- set context = "installation-config-parameters-generic" %}

Before you deploy an {{ product_title }} cluster, you create the `install-config.yaml` file and provide parameters to customize your cluster and the platform that hosts it.
You can then modify the `install-config.yaml` file to customize your cluster further. {._abstract}
