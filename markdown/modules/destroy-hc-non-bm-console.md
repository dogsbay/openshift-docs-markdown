# Destroying a hosted cluster on non-bare-metal agent machines by using the web console {id="destroy-hc-non-bm-console_{{ context }}"}

You can use the {{ mce_short }} web console to destroy a hosted cluster on non-bare-metal agent machines. {._abstract}

**Procedure**

1.  In the console, click **Infrastructure** → **Clusters**.
1.  On the **Clusters** page, select the cluster that you want to destroy.
1.  In the **Actions** menu, select **Destroy clusters** to remove the cluster.
