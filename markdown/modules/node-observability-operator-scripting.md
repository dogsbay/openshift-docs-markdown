# Node Observability Operator scripting {id="node-observability-operator-scripting_{{ context }}"}

Scripting allows you to run pre-configured bash scripts, using the current Node Observability Operator and Node Observability Agent. {._abstract}

These scripts monitor key metrics like CPU load, memory pressure, and worker node issues. They also collect sar reports and custom performance metrics.
