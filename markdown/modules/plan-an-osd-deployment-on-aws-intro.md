# Plan an {{ product_title }} deployment on AWS {id="plan-an-osd-deployment-on-aws-intro_{{ context }}"}

Before deploying Red&#160;Hat {{ product_title }} on Amazon Web Services (AWS), you must plan your deployment by understanding subscription models, network architecture, authentication options, encryption strategies, and compute resource requirements. {._abstract}

The planning phase ensures that your {{ product_title }} cluster meets your organization’s technical, security, and operational requirements. This includes selecting the appropriate Customer Cloud Subscription (CCS) model, designing network capacity and placement, defining access controls for users and applications, planning outbound connectivity, choosing cloud authentication methods, determining encryption strategies, and sizing compute resources appropriately.
