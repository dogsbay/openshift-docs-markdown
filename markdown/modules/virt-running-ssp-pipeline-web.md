# Running the example pipelines using the web console {id="virt-running-tto-pipeline-web_{{ context }}"}

You can run the example pipelines from the **Pipelines** menu in the web console. {._abstract}

**Procedure**

1.  Click **Pipelines** → **Pipelines** in the side menu.
1.  Select a pipeline to open the **Pipeline details** page.
1.  From the **Actions** list, select **Start**. The **Start Pipeline** dialog is displayed.
1.  Keep the default values for the parameters and then click **Start** to run the pipeline. The **Details** tab tracks the progress of each task and displays the pipeline status.
