# Creating account roles {id="cloud-experts-getting-started-detailed-ui-account-roles_{{ context }}"}

You can create your account roles using the {{ rosa_cli }} tool. {._abstract}

**Procedure**

1.  Create your account roles by running the following command:
    ```terminal
    $ rosa create account-roles --mode auto
    ```
1.  Click **OK** to close the sidebar.
