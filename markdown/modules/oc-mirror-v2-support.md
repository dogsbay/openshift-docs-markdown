# oc-mirror plugin v2 compatibility and support {id="oc-mirror-v2-support_{{ context }}"}

The oc-mirror plugin v2 is supported for {{ product_title }}. {._abstract}


:::note

On `aarch64`, `ppc64le`, and `s390x` architectures the oc-mirror plugin v2 is supported only for {{ product_title }} 4.14 and later.

:::


Use the latest available version of the oc-mirror plugin v2 regardless of which versions of {{ product_title }} you need to mirror.
