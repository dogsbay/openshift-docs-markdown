# Install a two-node cluster with fencing {id="install-a-two-node-cluster-with-fencing-intro_{{ context }}"}

A two-node {{ product_title }} cluster with fencing (TNF) provides high availability (HA) with a reduced hardware footprint. This configuration is designed for distributed or edge environments where deploying a full three-node control plane cluster is not practical.
