# Software prerequisites for an image-based installation and deployment {id="ztp-image-based-upgrade-prereqs_{{ context }}"}

An image-based installation and deployment requires the following minimum software versions for these required components. {._abstract}

**Minimum software requirements**

| Component | Software version |
| --- | --- |
| Managed cluster version | 4.17 |
| Hub cluster version | 4.16 |
| {{ rh_rhacm_first }} | 2.12 |
| {{ lcao }} | 4.16 or later |
| Image Based Install Operator | 4.17 |
| `openshift-install` program | 4.17 |
