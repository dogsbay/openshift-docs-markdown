# Change the configuration of compute machines by updating compute machine resources {id="change-the-configuration-of-compute-machines-by-updating-compute-machine-resources-con_{{ context }}"}

You can change the configuration that applies to compute machines by editing the resource that defines them, such as a compute machine set or a Cluster API machine template. Machines that already exist keep their current configuration, so they must be replaced before the change takes effect.
