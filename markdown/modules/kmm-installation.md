# Installing the Kernel Module Management Operator {id="kmm-install_{{ context }}"}

As a cluster administrator, you can install the Kernel Module Management (KMM) Operator on {{ product_title }} by using the OpenShift CLI or web console. {._abstract}

The KMM Operator is supported on {{ product_title }} 4.12 and later.
Installing KMM on version 4.11 does not require specific additional steps.
For details on installing KMM on version 4.10 and earlier, see the section "Installing the Kernel Module Management Operator on earlier versions of {{ product_title }}".
