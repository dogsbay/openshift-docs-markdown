# Find supported Red Hat container images {id="deploy-applications-with-red-hat-s2i-images-61-find-supported-red-hat-container-images-con_{{ context }}"}

Red Hat Universal Base Images (UBI) are the supported, redistributable base layers for containers that run on {{ product_title }}. Choosing a UBI base image means the image is covered by Red Hat support and can be freely redistributed.
