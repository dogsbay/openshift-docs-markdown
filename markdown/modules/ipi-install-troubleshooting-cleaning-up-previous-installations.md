# Cleaning up previous installations {id="ipi-install-troubleshooting-cleaning-up-previous-installations_{{ context }}"}

You must remove the artifacts from any failed deployment attempt before trying to deploy {{ product_title }} again. {._abstract}

**Procedure**

1.  Power off all bare-metal nodes before installing the {{ product_title }} cluster by running the following command:
    ```terminal
    $ ipmitool -I lanplus -U <user> -P <password> -H <management_server_ip> power off
    ```
1.  Remove all old bootstrap resources if any remain from an earlier deployment attempt by running the following script:
    ```bash
    for i in $(sudo virsh list | tail -n +3 | grep bootstrap | awk {'print $2'});
    do
      sudo virsh destroy $i;
      sudo virsh undefine $i;
      sudo virsh vol-delete $i --pool $i;
      sudo virsh vol-delete $i.ign --pool $i;
      sudo virsh pool-destroy $i;
      sudo virsh pool-undefine $i;
    done
    ```
1.  Delete the artifacts that the earlier installation generated by running the following command:
    ```terminal
    $ cd ; /bin/rm -rf auth/ bootstrap.ign master.ign worker.ign metadata.json \
    .openshift_install.log .openshift_install_state.json
    ```
1.  Re-create the {{ product_title }} manifests by running the following command:
    ```terminal
    $ ./openshift-baremetal-install --dir ~/clusterconfigs create manifests
    ```
