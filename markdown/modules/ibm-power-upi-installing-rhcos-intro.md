# Installing {{ op_system }} and starting the {{ product_title }} bootstrap process {id="ibm-power-upi-installing-rhcos-intro_{{ context }}"}

To install {{ product_title }} on {{ ibm_power_name }} infrastructure that you provision, you must install {{ op_system_first }} on the machines by using an ISO image or network PXE booting. {._abstract}

To install {{ op_system }}, you must give the Ignition config file generated by the {{ product_title }} installation program for the type of machine you are installing. If you have configured suitable networking, DNS, and load balancing infrastructure, the {{ product_title }} bootstrap process begins automatically after the {{ op_system }} machines have rebooted.

Follow either the steps to use an ISO image or network PXE booting to install {{ op_system }} on the machines.
