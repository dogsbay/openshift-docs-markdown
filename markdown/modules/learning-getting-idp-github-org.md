# Creating a GitHub organization {id="learning-getting-started-idp-github-org_{{ context }}"}

To use GitHub as your identity provider (IDP), configure an organization within your GitHub account, and set yourself as an administrator. {._abstract}


:::tip

If you are already an administrator in an existing organization and you want to use that organization, skip to the next section "Setting up an IDP with GitHub".

:::


**Procedure**

1.  Log in to your GitHub account.
1.  Click the **+** icon, then click **New Organization**.
    ![cloud-experts-getting-started-idp-new-org](/_assets/images/cloud-experts-getting-started-idp-new-org.png)
1.  Choose the most applicable plan for your situation or click **Join for free**.
1.  Enter an organization account name, an email, and whether it is a personal or business account. Then, click **Next**.
    ![cloud-experts-getting-started-idp-team](/_assets/images/cloud-experts-getting-started-idp-team.png)
1.  **Optional:** Add the GitHub IDs of other users to grant additional access to your {{ product_title }} cluster. You can also add them later.
1.  Click **Complete Setup**.
1.  **Optional:** Enter the requested information on the following page.
1.  Click **Submit**.
