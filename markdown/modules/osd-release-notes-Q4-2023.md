# Q4 2023 {id="osd-q4-2023_{{ context }}"}

The following items were added during the fourth quarter of 2023. {._abstract}


Policy constraint update
:   {{ product_title }} on {{ gcp_full }} users can now enable UEFISecureBoot during cluster installation, as required by the {{ gcp_full }} ShieldVM policy. This new feature adds further protection from boot or kernel-level malware or rootkits.


Cluster install update
:   {{ product_title }} clusters can now be installed on {{ gcp_full }} shared VPCs.


{{ product_title }} on {{ gcp_full }} Marketplace availability
:   When creating an {{ product_title }} cluster on {{ gcp_full }} through the Hybrid Cloud Console, customers can now select {{ gcp_full }} Marketplace as their preferred billing model. This billing model allows Red&#160;Hat customers to take advantage of their [Google Committed Use Discounts (CUD)](https://cloud.google.com/docs/cuds) towards {{ product_title }} purchased through the {{ gcp_full }} Marketplace.
