# Deleting your cluster {id="deleting-cluster_aws_{{ context }}"}

Delete your {{ product_title }} cluster from your {{ AWS }} infrastructure to stop incurring costs and consuming cloud resources.  {._abstract}

**Prerequisites**

*   You logged in to {{ cluster_manager_url }}.
*   You created an {{ product_title }} cluster.

**Procedure**

1.  From {{ cluster_manager_url }}, click the cluster you want to delete.
1.  Select **Delete cluster** from the **Actions** list.
1.  Type the name of the cluster highlighted in bold, then click **Delete**. Cluster deletion occurs automatically.
