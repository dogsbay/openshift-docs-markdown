# View the FlowCollector resource {id="network-observability-flowcollector-view_{{ context }}"}

View and modify the `FlowCollector` resource in the {{ product_title }} web console through the integrated setup, advanced form, or by editing the YAML directly to configure the Network Observability Operator. {._abstract}

**Procedure**

1.  In the web console, navigate to **Ecosystem** -> **Installed Operators**.
1.  Under the **Provided APIs** heading for the **NetObserv Operator**, select **Flow Collector**.
1.  Select **cluster** then select the **YAML** tab. There, you can modify the `FlowCollector` resource to configure the Network Observability Operator.
