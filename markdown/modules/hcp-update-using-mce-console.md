# Updating a hosted cluster by using the {{ mce_short }} console {id="hcp-update-using-mce-console_{{ context }}"}

You can update your hosted cluster by using the {{ mce_short }} console. {._abstract}


:::important

Before updating a hosted cluster, you must refer to the available and conditional updates of a hosted cluster. Choosing a wrong release version might break the hosted cluster.

:::


**Procedure**

1.  Select **All clusters**.
1.  Navigate to **Infrastructure** -> **Clusters** to view managed hosted clusters.
1.  Click the **Upgrade available** link to update the control plane and node pools.
