# SPIRE Server and Agent telemetry {id="zero-trust-manager-server-agent-telemetry_{{ context }}"}

Use the SPIRE Controller Manager to register workloads by using custom resource definitions (CRDs). The manager monitors pods and CRDs for changes and triggers a reconciliation process. This process creates, updates, or deletes SPIRE Server entries to help ensure they match your configuration. {._abstract}
