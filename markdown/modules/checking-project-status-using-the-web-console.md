# Checking project status by using the web console {id="checking-project-status-using-the-web-console_{{ context }}"}

You can review the status of your project by using the web console. {._abstract}

**Prerequisites**

*   You have created a project.

**Procedure**

1.  Navigate to **Home** -> **Projects**.
1.  Select a project from the list.
1.  Review the project status in the **Overview** page.
