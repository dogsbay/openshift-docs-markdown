# Service CA certificates {id="troubleshooting-certs-auto-service-ca_{{ context }}"}

The `service-ca` is an Operator that creates a self-signed certificate authority (CA) when an {{ product_title }} cluster is deployed.
This allows user to add certificates to their deployments without manually creating them. 
Service CA certificates are self-signed certificates. {._abstract}

For more information, see "Service CA certificates" in _Security and compliance_.
