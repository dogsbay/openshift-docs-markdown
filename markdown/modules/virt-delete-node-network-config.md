# Deleting the policy {id="virt-delete-node-network-config_{{ context }}"}

You can delete a `NodeNetworkConfigurationPolicy` object when it is no longer needed. {._abstract}

**Procedure**

1.  Navigate to **Networking** → **NodeNetworkConfigurationPolicy**.
1.  In the **NodeNetworkConfigurationPolicy** page, click the {{ kebab }} icon placed next to the policy you want to delete, and click **Delete**.
1.  In the pop-up window, enter the policy name to confirm deletion, and click **Delete**.
