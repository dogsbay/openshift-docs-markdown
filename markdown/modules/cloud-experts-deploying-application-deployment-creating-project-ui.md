# Creating a new project by using the web console {id="cloud-experts-deploying-application-deployment-creating-project-ui_{{ context }}"}

You can create your project using {{ cluster_manager }}. {._abstract}

**Procedure**

1.  From the web console, click **Home -> Projects**. 
1.  On the **Projects** page, click create **Create Project**.
