# Manually upgrading your cluster using the UI {id="learning-getting-started-upgrading-web-ui_{{ context }}"}

You can upgrade your cluster using {{ cluster_manager_url }}. {._abstract}

**Procedure**

1.  Log in to the {{ cluster_manager }}, and select the cluster you want to upgrade.
1.  Click the **Settings** tab.
1.  If an upgrade is available, click **Update**.
    ![cloud-experts-getting-started-cluster-upgrade](/_assets/images/cloud-experts-getting-started-cluster-upgrade.png)
1.  Select the version to which you want to upgrade in the new window.
1.  Schedule a time for the upgrade or begin it immediately.
