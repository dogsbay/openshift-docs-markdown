# Configure the Network Observability Operator FlowCollector {id="configure-the-network-observability-operator-flowcollector-con_{{ context }}"}

The `FlowCollector` custom resource (CR) is the single place where the Network Observability Operator is configured. Edit it to control which network traffic is captured, how flows are enriched, and how the collection components are deployed.
