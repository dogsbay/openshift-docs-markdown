# Restart hosted control plane components and pause reconciliation {id="restart-hosted-control-plane-components-and-pause-reconciliation-con_{{ context }}"}

You can restart the components of a hosted control plane to recover from a transient failure, and you can pause reconciliation so that the HyperShift Operator stops applying the desired state while you make a manual change.
