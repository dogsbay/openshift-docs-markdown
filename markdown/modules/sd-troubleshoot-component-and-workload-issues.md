# Troubleshoot component and workload issues {id="sd-troubleshoot-component-and-workload-issues_{{ context }}"}

Cluster administrators and application teams need to diagnose and resolve problems with the components and workloads that run on their {{ product_title }} cluster so that their applications stay healthy and available. {._abstract}

Troubleshooting components and workloads helps you:

*   **Identify causes**: Distinguish workload failures from problems in supporting components.
*   **Keep applications running**: Detect and resolve workload failures before they affect your users.
*   **Restore application health**: Apply corrective actions within your control and recognize when a problem requires escalating to Red&#160;Hat.
