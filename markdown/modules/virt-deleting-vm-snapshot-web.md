# Deleting a snapshot by using the web console {id="virt-deleting-vm-snapshot-web_{{ context }}"}

You can delete an existing virtual machine (VM) snapshot by using the web console. {._abstract}

**Procedure**

1.  Navigate to **Virtualization** -> **VirtualMachines** in the web console.
1.  Select a VM to open the **VirtualMachine details** page.
1.  Click the **Snapshots** tab to view a list of snapshots associated with the VM.
1.  Click the Options menu {{ kebab }} beside a snapshot and select **Delete snapshot**.
1.  Click **Delete**.
