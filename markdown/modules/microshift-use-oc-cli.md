# Use the oc CLI {id="microshift-use-oc-cli_{{ context }}"}

The `oc` CLI tool provides a superset of `kubectl` functionality for interacting with {{ microshift_short }}. You can use `oc` to view resource status, retrieve logs, and run commands against the cluster. {{ microshift_short }} supports a subset of `oc` commands that are relevant to single-node edge deployments.
