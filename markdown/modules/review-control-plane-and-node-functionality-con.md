# Review control plane and node functionality {id="review-control-plane-and-node-functionality-con_{{ context }}"}

You can use a _control plane_, which is composed of control plane machines, to manage the {{ product_title }} cluster. The control plane machines manage workloads on the compute machines, which run {{ op_system_first }}, a container-optimized operating system that the cluster configures and updates for you.
