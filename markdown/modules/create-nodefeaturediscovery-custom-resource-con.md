# Create a NodeFeatureDiscovery custom resource {id="create-nodefeaturediscovery-custom-resource-con_{{ context }}"}

The Node Feature Discovery (NFD) Operator starts its workers only after you create a `NodeFeatureDiscovery` custom resource. You can create the CR from the CLI or the web console, including on a disconnected cluster.
