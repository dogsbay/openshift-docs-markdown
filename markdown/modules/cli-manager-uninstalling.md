# Uninstalling the {{ cli_manager }} {id="cli-manager-uninstalling_{{ context }}"}

You can uninstall the {{ cli_manager }} by using the web console.

**Prerequisites**

*   You are logged in to {{ product_title }} as a user with the `cluster-admin` role.
*   You have access to the {{ product_title }} web console.
*   The {{ cli_manager }} is installed.

**Procedure**

1.  Log in to the {{ product_title }} web console.
1.  Uninstall the {{ cli_manager }} by completing the following steps:
    1.  Navigate to **Ecosystem** → **Installed Operators**.
    1.  Click the Options menu {{ kebab }} next to the **{{ cli_manager }}** entry and click **Uninstall Operator**.
    1.  In the confirmation dialog, click **Uninstall**.
