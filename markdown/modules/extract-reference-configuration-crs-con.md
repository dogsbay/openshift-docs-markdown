# Extract telco core reference configuration CRs {id="extract-reference-configuration-crs-con_{{ context }}"}

The telco core reference design ships as a set of custom resources (CRs) that you extract from a container image. Use these CRs as the baseline for node, infrastructure, resource tuning, networking, scheduling, storage, and security configuration.
