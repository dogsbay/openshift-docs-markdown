# Manage hosts and monitor hardware events {id="manage-bare-metal-host-lifecycle-manage-hosts-and-monitor-hardware-events-con_{{ context }}"}

A `BareMetalHost` resource represents a physical machine that the bare-metal provisioning service manages. You add hosts to the cluster, take them in and out of maintenance, and power them off from either the web console or the CLI.
