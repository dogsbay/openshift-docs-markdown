# Troubleshoot cluster infrastructure issues {id="rosa-troubleshoot-cluster-infrastructure-issues_{{ context }}"}

Cluster administrators and Site Reliability Engineering (SRE) teams need to identify and resolve infrastructure-level problems so that their {{ product_title }} clusters stay available and performant. {._abstract}

Troubleshooting cluster infrastructure helps you:

*   **Diagnose infrastructure problems**: Investigate installation failures, network connectivity problems, and node-health symptoms to understand what is affecting cluster operation.
*   **Minimize downtime**: Restore cluster health before problems affect your workloads.
*   **Support cluster recovery**: Address configuration or capacity issues within your control, and gather relevant diagnostics for problems that require escalation to Red&#160;Hat.
