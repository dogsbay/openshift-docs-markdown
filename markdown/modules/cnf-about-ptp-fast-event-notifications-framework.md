# About the PTP fast event notifications framework {id="cnf-about-ptp-fast-event-notifications-framework-{{ ptp_events_rest_api }}_{{ context }}"}

Use the Precision Time Protocol (PTP) fast event REST API v2 to subscribe cluster applications to PTP events that the bare-metal cluster node generates.


:::note

The fast events notifications framework uses a REST API for communication. The PTP events REST API v2 is based on the _O-RAN O-Cloud Notification API Specification for Event Consumers 4.0_ that is available from [O-RAN ALLIANCE Specifications](https://orandownloadsweb.azurewebsites.net/specifications).

:::
