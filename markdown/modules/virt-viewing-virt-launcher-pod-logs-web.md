# Viewing virt-launcher pod logs with the web console {id="virt-viewing-virt-launcher-pod-logs-web_{{ context }}"}

To diagnose and troubleshoot virtual machine issues, you can view the `virt-launcher` pod logs by using the {{ product_title }} web console.  {._abstract}

**Procedure**

1.  Navigate to **Virtualization** → **VirtualMachines**.
1.  Select a virtual machine to open the **VirtualMachine details** page.
1.  On the **General** tile, click the pod name to open the **Pod details** page.
1.  Click the **Logs** tab to view the logs.
