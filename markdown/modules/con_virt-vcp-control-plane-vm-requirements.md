# Control plane VM requirements {id="con_virt-vcp-control-plane-vm-requirements_{{ context }}"}

Each control plane VM must meet minimum resource requirements to run the {{ product_title }} control plane components reliably. {._abstract}

Each control plane VM requires the following minimum resources:

*   8 vCPUs
*   16 GiB RAM
*   120 GiB storage
