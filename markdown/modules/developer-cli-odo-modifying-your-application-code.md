# Modifying your application code {id="modifying-your-application-code_{{ context }}"}

You can modify your application code and have the changes applied to your application on {{ product_title }}.

1.  Edit one of the layout files within the Node.js directory with your preferred text editor.
1.  Update your component:
    ```terminal
    $ odo push
    ```
1.  Refresh your application in the browser to see the changes.
