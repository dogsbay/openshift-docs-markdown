# Configuring an {{ ibm_cloud_title }} account {id="ibm-cloud-account-ibm-power-vs-intro_{{ context }}"}

To install {{ product_title }} on {{ ibm_power_server_name }}, you must configure an {{ ibm_cloud_name }} account with the correct quotas, DNS resolution, and IAM policies. {._abstract}

## Prerequisites {id="_prerequisites"}

*   You have an {{ ibm_cloud_name }} account with a subscription. You cannot install {{ product_title }} on a free or on a trial {{ ibm_cloud_name }} account.
