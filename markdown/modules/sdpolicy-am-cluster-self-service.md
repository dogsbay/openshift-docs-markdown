# Cluster self-service {id="cluster-self-service_{{ context }}"}

Customers can create, scale, and delete their clusters from {{ cluster_manager_url }}, provided that they have already purchased the necessary subscriptions. {._abstract}

Actions available in {{ cluster_manager_first }} must not be directly performed from within the cluster as this might cause adverse affects, including having all actions automatically reverted.
