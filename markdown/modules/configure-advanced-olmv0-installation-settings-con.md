# Configure advanced Operator installation settings with {{ olmv0 }} {id="configure-advanced-olmv0-installation-settings-con_{{ context }}"}

Operator groups control which namespaces an Operator watches and how Operator Lifecycle Manager (OLM) manages related Operators in {{ product_title }}. You can use them to configure install modes, target namespaces, and access for OLM-managed Operators.
