# oc CLI commands reference {id="microshift-oc-cli-commands-reference_{{ context }}"}

This reference covers the `oc` and `oc adm` commands available for use with {{ microshift_short }}. The `oc` binary provides commands for managing applications, resources, and cluster state. The `oc adm` commands cover cluster administration tasks. {{ microshift_short }} supports a subset of the full {{ OCP }} command set.
