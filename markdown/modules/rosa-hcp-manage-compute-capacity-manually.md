# Manage compute capacity manually {id="rosa-hcp-manage-compute-capacity-manually_{{ context }}"}

As a cluster administrator, you can manage compute capacity for your cluster manually by configuring machine pools. You can label and taint nodes, configure node auto-repair and drain behavior, set disk volume sizes, and add or remove machine pools as your workload needs change.
