# Compute machine creation on user-provisioned infrastructure {id="machine-mgmt-intro-add-for-upi_{{ context }}"}

User-provisioned infrastructure is an environment where you can deploy infrastructure such as compute, network, and storage resources that host the {{ product_title }}. You can add compute machines to a cluster on user-provisioned infrastructure during or after the installation process.
