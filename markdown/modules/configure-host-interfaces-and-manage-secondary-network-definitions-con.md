# Configure host interfaces and manage secondary network definitions {id="configure-host-interfaces-and-manage-secondary-network-definitions-con_{{ context }}"}

Secondary networks that map to a physical interface or VLAN depend on how the host interface is configured and on the `NetworkAttachmentDefinition` that describes the attachment. You can edit those definitions as requirements change and remove them when a network is no longer needed.
