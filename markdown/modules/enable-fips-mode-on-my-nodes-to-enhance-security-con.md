# Enable FIPS mode on your nodes {id="enable-fips-mode-on-my-nodes-to-enhance-security-con_{{ context }}"}

To meet federal cryptographic standards, you can run {{ product_title }} in FIPS mode so that the cluster uses only FIPS-validated cryptographic modules. FIPS mode is selected when you install the cluster and applies to every node.
