# About GitHub authentication {id="identity-provider-github-about_{{ context }}"}

Configure GitHub authentication so users can log in with GitHub or GitHub Enterprise credentials. Separate {{ product_title }} user accounts are not required. {._abstract}

To prevent anyone with any GitHub user ID from logging in to your {{ product_title }} cluster, you can restrict access to only those in specific GitHub organizations.
