# Scale a user-provisioned infrastructure cluster with the Bare Metal Operator {id="scale-a-upi-cluster-with-the-bare-metal-operator-intro_{{ context }}"}

You can use the Bare Metal Operator (BMO) to provision and manage bare-metal hosts in a cluster that was installed on user-provisioned infrastructure. Scaling a user-provisioned cluster with the BMO lets you add compute nodes without re-provisioning the cluster.
