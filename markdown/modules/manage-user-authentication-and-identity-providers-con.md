# Manage user authentication and identity providers {id="manage-user-authentication-and-identity-providers-con_{{ context }}"}

{{ product_title }} authenticates every request to the API against a user identity that an identity provider supplies. By configuring identity providers, OAuth clients, and token policy, you control how team members and external tools log in to the cluster and how long their sessions remain valid.
