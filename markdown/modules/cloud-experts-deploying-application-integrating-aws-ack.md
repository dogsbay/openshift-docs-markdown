# Amazon Controller for Kubernetes (ACK) {id="cloud-experts-deploying-application-integrating-aws-ack_{{ context }}"}

With ACK, you can create an S3 bucket, integrate it with the OSToy application, upload a file to it, and view the file in your application. {._abstract}

**Procedure**

*   Use the [ACK](https://aws-controllers-k8s.github.io/community/docs/community/overview/) to create and use AWS services directly from Kubernetes. You can deploy your applications directly in the Kubernetes framework by using a familiar structure to declaratively define and create AWS services such as S3 buckets or Relational Database Service (RDS) databases.
