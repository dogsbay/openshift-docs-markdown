# Ingress and egress requirements for {{ hcp }} {id="hcp-ingress-egress-reqs_{{ context }}"}

Open network ports to enable communication between the management cluster, {{ hcp }} components, and compute nodes. Categorize them into ingress ports for incoming traffic to {{ hcp }} and egress ports for outgoing traffic from {{ hcp }}.
