# Enable a dynamic plugin with the CLI {id="enable-a-dynamic-plugin-with-the-cli-con_{{ context }}"}

After a scripted installation, you can activate a dynamic plugin without opening the web console. Patching the console Operator configuration with the {{ oc_first }} adds the plugin to the list of enabled plugins, which lets you enable plugins from an automated workflow.
