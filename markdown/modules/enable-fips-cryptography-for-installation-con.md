# Enable FIPS cryptography for installation {id="enable-fips-cryptography-for-installation-con_{{ context }}"}

If your environment must meet FIPS 140-2 requirements, you can install an {{ product_title }} cluster in FIPS mode. You must enable FIPS mode when you install the cluster; you cannot convert a cluster afterwards.
