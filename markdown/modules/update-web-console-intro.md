# Update a cluster using the web console {id="updating-cluster-web-console_{{ context }}"}

You can perform minor version and patch updates on an {{ product_title }} cluster by using the web console. {._abstract}


:::note

Use the web console or `oc adm upgrade channel _<channel>_` to change the update channel. You can follow the steps in "Updating a cluster using the CLI" to complete the update after you change to a {{ product_version }} channel.

:::
