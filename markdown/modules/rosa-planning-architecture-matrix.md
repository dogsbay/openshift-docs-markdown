# OpenShift 5 cluster availability matrix {id="rosa-planning-architecture-matrix_{{ context }}"}

The following matrix details the availability of OpenShift versions based on cluster architecture (classic compared to hosted control planes). {._abstract}

**OpenShift version availability by architecture**

| Operation | Classic clusters | Hosted control planes (HCP) clusters |
| --- | --- | --- |
| **OpenShift 5.x Installs** | Not Supported | Supported |
| **Upgrades to OpenShift 5.x** | Not Supported | Supported (from 4.x HCP) |
| **OpenShift 4.x Installs** | Supported | Supported |
