# {{ microshift_short }} Observability overview {id="microshift-observability-overview_{{ context }}"}

{{ microshift_short }} Observability collects and transmits system data for monitoring and analysis. The data includes performance and usage metrics, and error reporting. {._abstract}

To set up observability for your {{ microshift_short }} node, you must complete the following steps:

*   Install and enable {{ microshift_short }} Observability.
*   Configure the observability service for your environment.
*   Select a configuration size that matches your workload needs.
*   Verify the observability service is running correctly.
