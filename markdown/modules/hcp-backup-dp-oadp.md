# Data plane workload backup {id="hcp-backup-dp-oadp_{{ context }}"}

As part of the process to back up and restore by using the {{ oadp_short }} Operator, you can back up the data plane workload. {._abstract}

If the data plane workload is not important, you can skip this procedure. 

To back up the data plane workload by using the {{ oadp_short }} Operator, see "Backing up applications". After you complete those steps, you can restore your hosted cluster by using {{ oadp_short }}.
