# How you can use the Cluster Samples Operator {id="how-you-can-use-the-cluster-samples-operator_{{ context }}"}

To manage sample image streams and templates in {{ product_title }}, you can use the Cluster Samples Operator. The Cluster Samples Operator creates default samples during initial startup to initiate image streams and templates in the `openshift` namespace.
