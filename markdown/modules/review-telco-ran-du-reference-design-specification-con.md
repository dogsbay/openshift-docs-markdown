# Review the telco RAN DU reference design specification {id="review-telco-ran-du-reference-design-specification-con_{{ context }}"}

The telco RAN distributed unit (DU) reference design specification (RDS) defines the validated scope and software versions for RAN DU clusters. Review it, and the rules for deviating from it, before you plan your deployment.
