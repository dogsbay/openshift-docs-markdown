# Provision bare metal nodes with Red Hat Bare-Metal-as-a-Service {id="use-red-hat-bare-metal-as-a-service-for-openshift-intro_{{ context }}"}

You can provision and manage bare-metal hosts by using the Metal^3^ API and the Bare Metal Operator (BMO). These hosts, external to the {{ product_title }} cluster, can run workloads that require direct hardware access.
