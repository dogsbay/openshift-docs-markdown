# Troubleshoot hosted clusters on bare metal {id="troubleshoot-hosted-clusters-by-platform-troubleshoot-hosted-clusters-on-bare-metal-con_{{ context }}"}

On bare metal, a hosted cluster depends on the agent platform to discover and provision machines. When nodes are not added to the hosted cluster, the cause is usually in agent discovery or in the {{ op_system }} boot.
