# Tune kernel behaviors on my nodes by adding kernel arguments {id="tune-kernel-behaviors-on-my-nodes-by-adding-kernel-arguments-con_{{ context }}"}

You can set kernel boot arguments on the nodes in a pool with a machine config, either during installation or afterwards. Use kernel arguments to tune node performance, enable hardware features, or meet security requirements.
