# Viewing downward metrics {id="virt-viewing-downward-metrics_{{ context }}"}

You can view downward metrics by using either the command-line interface (CLI), or the `vm-dump-metrics` tool. {._abstract}


:::note

On Red Hat Enterprise Linux (RHEL) 9, use the command line to view downward metrics. The vm-dump-metrics tool is not supported on the Red Hat Enterprise Linux (RHEL) 9 platform.

:::
