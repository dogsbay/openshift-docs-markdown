# Removing a horizontal pod autoscaler by using the web console {id="nodes-pods-autoscaling-creating-web-console-remove_{{ context }}"}

You can use the web console to remove a horizontal pod autoscaler (HPA). {._abstract}

**Procedure**

1.  In the **Topology** view, click the node to reveal the side panel.
1.  From the **Actions** drop-down list, select **Remove HorizontalPodAutoscaler**.
1.  In the confirmation window, click **Remove** to remove the HPA.
