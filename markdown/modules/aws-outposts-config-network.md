# Configuring your network for your Outpost {id="aws-outposts-network-config_{{ context }}"}

To extend your VPC cluster into an Outpost, you must complete two network configuration tasks. {._abstract}

The following network configuration tasks must be completed:

*   Change the Cluster Network MTU.
*   Create a subnet in your Outpost.
