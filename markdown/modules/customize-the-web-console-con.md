# Customize the web console {id="customize-the-web-console-con_{{ context }}"}

You can customize the {{ product_title }} web console to meet corporate or regulatory standards. As a cluster administrator, you can add your own logo and login page branding, define custom links and notification banners, change the console and download routes, and tailor which perspectives and developer catalog items users see.
