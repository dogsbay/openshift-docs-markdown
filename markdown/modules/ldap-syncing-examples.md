# LDAP group sync examples {id="ldap-syncing-examples_{{ context }}"}

Review LDAP group sync examples so you can configure synchronization for RFC 2307, Active Directory, or augmented Active Directory schemas. {._abstract}


:::note

These examples cover only direct group membership. Each user is a direct member of a group, and groups do not contain other groups as members. For information, see "LDAP nested membership sync".

:::
