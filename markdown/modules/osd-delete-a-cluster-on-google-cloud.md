# Delete an OSD cluster on {{ GCP }} {id="osd-delete-a-cluster-on-google-cloud_{{ context }}"}

When you no longer need an {{ product_title }} cluster on {{ GCP }}, delete it and release the {{ GCP }} resources that it used. Deleting the cluster through the supported workflow ensures that the service removes the resources that it provisioned.
