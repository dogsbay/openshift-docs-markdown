# Installing the DPU Operator {id="overview-installing-dpu-operator_{{ context }}"}

You can install the Data Processing Unit (DPU) Operator on both host and DPU clusters to manage device lifecycle and network attachments by using the CLI or web console. {._abstract}

Cluster administrators can install the DPU Operator on the host cluster and all DPU clusters by using the {{ product_title }} CLI or the web console. The DPU Operator manages the lifecycle, DPU devices, and network attachments for all supported DPUs.


:::note

You need to install the DPU Operator on the host cluster and each of the DPU clusters.

:::
