# Configure browser-based access to the API server {id="configure-browser-based-access-to-the-api-server-con_{{ context }}"}

By default, the cluster only permits the web console to make browser-based requests to the API server. To let a trusted internal portal or browser-based application query cluster data, you must add its hostname to the API server configuration.
