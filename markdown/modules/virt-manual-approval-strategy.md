# Manual approval strategy {id="virt-manual-approval-strategy_{{ context }}"}

If you use the **Manual** approval strategy, you must approve every pending update. If {{ product_title }} and {{ VirtProductName }} updates are out of sync, your cluster becomes unsupported. {._abstract}

To avoid risk to cluster supportability and functionality, use the **Automatic** approval strategy. If you must use the **Manual** approval strategy, approve pending Operator updates as soon as they become available.
