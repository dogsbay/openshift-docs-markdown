# Collect and analyze application and infrastructure logs {id="sd-collect-and-analyze-logs_{{ context }}"}

You can deploy {{ logging }} on your {{ product_title }} cluster to collect and aggregate node system audit logs, application container logs, and infrastructure logs. {._abstract}

You can use {{ logging }} to perform the following tasks:

*   Forward logs to your chosen log outputs, including on-cluster, Red&#160;Hat managed log storage.
*   Visualize your log data in the {{ product_title }} web console.

Because {{ logging }} releases on a different cadence from {{ product_title }}, the {{ logging }} documentation is available as a separate documentation set at [Red&#160;Hat {{ OCP_short }} {{ logging_uc }}](https://docs.redhat.com/en/documentation/red_hat_openshift_logging/).
