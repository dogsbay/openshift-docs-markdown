# Install a cluster with multi-architecture support {id="install-a-cluster-with-multi-architecture-support-con_{{ context }}"}

You can install an {{ product_title }} cluster with support for configuring multi-architecture compute machines. Configuring the installation program to use the `multi` payload lets you deploy control plane and compute nodes with the CPU architectures that your workloads require.
