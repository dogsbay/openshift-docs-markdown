# Dynamic storage with the LVMS plugin {id="microshift-dynamic-storage-LVMS-plugin_{{ context }}"}

{{ microshift_short }} provides dynamic storage provisioning that is ready for immediate use with the logical volume manager storage (LVMS) Container Storage Interface (CSI) provider. Dynamic provisioning creates storage volumes on-demand, eliminating the need for pre-provisioned storage.
