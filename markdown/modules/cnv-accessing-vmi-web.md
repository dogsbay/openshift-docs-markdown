# Connecting to a virtual machine with the web console {id="virt-accessing-vmi-web_{{ context }}"}

You can connect to a virtual machine by using the web console.

**Procedure**

1.  Ensure you are in the correct project. If not, click the **Project**
list and select the appropriate project.
1.  Click **Workloads** → **Virtual Machines** to display the virtual
machines in the project.
1.  Select a virtual machine.
1.  In the **Overview** tab, click the `virt-launcher-<vm-name>` pod.
1.  Click the **Terminal** tab. If the terminal is blank, click the
terminal and press any key to initiate connection.
