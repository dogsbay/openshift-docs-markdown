# Removing filters from {{ red_hat_lightspeed }} advisor service recommendations {id="removing-filters-from-insights-recommendations_{{ context }}"}

You can apply multiple filters to the list of recommendations. When ready, you can remove them individually or completely reset them. {._abstract}

**Procedure**

*   To remove default or non-default filters individually, click the **X** icon next to each filter.
*   To remove all non-default filters, click **Reset filters** to remove only the filters that you applied, leaving the default filters in place.
