# Change the control plane instance type {id="change-the-control-plane-instance-type-con_{{ context }}"}

You can move your control plane to a different instance type by updating the control plane machine set, which replaces the control plane machines one at a time. On {{ aws_short }}, you can make the change from the control plane machine set or from the {{ aws_short }} console.
