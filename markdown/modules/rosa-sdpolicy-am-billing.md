# Billing and pricing {id="rosa-sdpolicy-billing_{{ context }}"}

{{ product_title }} is billed directly to your {{ AWS }} account. {{ product_title }} pricing is consumption based, with annual commitments or three-year commitments for greater discounting. {._abstract}

The total cost of {{ product_title }} consists of two components:

*   {{ product_title }} service fees
*   AWS infrastructure fees

For more details, visit the "{{ product_title }} Pricing" page on the AWS website, linked in the _Additional resources_.
