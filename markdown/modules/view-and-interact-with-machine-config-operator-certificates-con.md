# View and interact with Machine Config Operator certificates {id="view-and-interact-with-machine-config-operator-certificates-con_{{ context }}"}

The Machine Config Operator manages the certificates that nodes use to join the cluster and to talk to the machine config server. You can view their status in the `MachineConfigPool` and `ControllerConfig` resources.
