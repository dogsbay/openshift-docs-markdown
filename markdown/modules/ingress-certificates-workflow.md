## Default certificate workflow {id="ingress-certificates-workflow-default_{{ context }}"}

![Default ingress certificate workflow](/images/default_4.5.svg)

<img src="/images/darkcircle-0.png" alt="20" width="20"> An empty `defaultCertificate` field causes the Ingress Operator to use a self-signed certificate authority (CA) to generate a serving certificate for the specified domain.

<img src="/images/darkcircle-1.png" alt="20" width="20"> The default CA certificate and key generated by the Ingress Operator. Used to sign Operator-generated default serving certificates.

<img src="/images/darkcircle-2.png" alt="20" width="20"> In the default workflow, the wildcard default serving certificate, created by the Ingress Operator and signed using the generated default CA certificate. In the custom workflow, this is the user-provided certificate.

<img src="/images/darkcircle-3.png" alt="20" width="20"> The router deployment. Uses the certificate in `secrets/router-certs-default` as its default front-end server certificate.

<img src="/images/darkcircle-4.png" alt="20" width="20"> In the default workflow, the contents of the wildcard default serving certificate (public and private parts) are copied here to enable OAuth integration. In the custom workflow, this is the user-provided certificate.

<img src="/images/darkcircle-5.png" alt="20" width="20"> The public (certificate) part of the default serving certificate. Replaces the `configmaps/router-ca` resource.

<img src="/images/darkcircle-6.png" alt="20" width="20"> The user updates the cluster proxy configuration with the CA certificate that signed the `ingresscontroller` serving certificate. This enables components like `auth`, `console`, and the registry to trust the serving certificate.

<img src="/images/darkcircle-7.png" alt="20" width="20"> The cluster-wide trusted CA bundle containing the combined {{ op_system_first }} and user-provided CA bundles or an {{ op_system }}-only bundle if a user bundle is not provided.

<img src="/images/darkcircle-8.png" alt="20" width="20"> The custom CA certificate bundle, which instructs other components (for example, `auth` and `console`) to trust an `ingresscontroller` configured with a custom certificate.

<img src="/images/darkcircle-9.png" alt="20" width="20"> The `trustedCA` field is used to reference the user-provided CA bundle.

<img src="/images/darkcircle-10.png" alt="20" width="20"> The Cluster Network Operator injects the trusted CA bundle into the `proxy-ca` config map.

<img src="/images/darkcircle-11.png" alt="20" width="20"> {{ product_title }} {{ product_version }} and newer use `default-ingress-cert`.
