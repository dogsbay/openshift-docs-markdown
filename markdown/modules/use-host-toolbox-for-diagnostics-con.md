# Use the host toolbox for diagnostics {id="use-host-toolbox-for-diagnostics-con_{{ context }}"}

When you need diagnostic tools that are not available on a {{ product_title }} node by default, you use the toolbox container to run commands directly on the host or install additional packages. You can also start an alternative diagnostic image and use the toolbox to gather diagnostic information for Red&#160;Hat support.
