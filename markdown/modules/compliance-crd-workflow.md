# Compliance Operator custom resource definition workflow {id="custom-resource-definitions-workflow_{{ context }}"}

You can use the Compliance Operator Custom Resource Definition (CRD) workflow to define requirements, configure settings, process scans, monitor compliance checks, and review results. {._abstract}

The CRD workflow includes the following steps:

1.  Define your compliance scan requirements.
1.  Configure the compliance scan settings.
1.  Process compliance requirements with compliance scans settings.
1.  Monitor the compliance scans.
1.  Check the compliance scan results.
