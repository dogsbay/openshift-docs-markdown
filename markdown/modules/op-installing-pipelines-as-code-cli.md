# Installing {{ pac }} CLI {id="installing-pipelines-as-code-cli_{{ context }}"}

Cluster administrators can use the `tkn pac` and `opc` CLI tools on local machines or as containers for testing. The `tkn pac` and `opc` CLI tools are installed automatically when you install the `tkn` CLI for {{ pipelines_title }}. {._abstract}

You can install the `tkn pac` and `opc` version `1.11.0` binaries for the supported platforms:

*   [Linux (x86_64, amd64)](https://mirror.openshift.com/pub/openshift-v4/clients/pipelines/1.11.0/tkn-linux-amd64.tar.gz)
*   [Linux on {{ ibm_z_name }} and {{ ibm_linuxone_name }} (s390x)](https://mirror.openshift.com/pub/openshift-v4/clients/pipelines/1.11.0/tkn-linux-s390x.tar.gz)
*   [Linux on {{ ibm_power_name }} (ppc64le)](https://mirror.openshift.com/pub/openshift-v4/clients/pipelines/1.11.0/tkn-linux-ppc64le.tar.gz)
*   [macOS](https://mirror.openshift.com/pub/openshift-v4/clients/pipelines/1.11.0/tkn-macos-amd64.tar.gz)
*   [Windows](https://mirror.openshift.com/pub/openshift-v4/clients/pipelines/1.11.0/tkn-windows-amd64.zip)
