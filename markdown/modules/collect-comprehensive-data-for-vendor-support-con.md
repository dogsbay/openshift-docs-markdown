# Collect comprehensive data for vendor support {id="collect-comprehensive-data-for-vendor-support-con_{{ context }}"}

When you cannot resolve a cluster issue yourself, you collect comprehensive diagnostic data so that Red&#160;Hat support can reproduce and diagnose the problem.  {._abstract}

You use tools such as `oc adm must-gather`, the Insights Operator log gatherer, and targeted image-specific gather commands to capture logs, events, and cluster state.
