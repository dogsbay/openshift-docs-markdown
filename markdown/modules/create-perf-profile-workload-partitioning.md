# Performance profiles and workload partitioning {id="performance-profile-workload-partitioning_{{ context }}"}

To enable workload partitioning, apply a performance profile. {._abstract}

An appropriately configured performance profile specifies the `isolated` and `reserved` CPUs. Create a performance profile by using the Performance Profile Creator (PPC) tool.
