# Installing the Local Storage Operator {id="local-storage-install-overview_{{ context }}"}

You can install the Local Storage Operator (LSO) to provision and manage local persistent storage volumes in your cluster. {._abstract}

1.  Create the `openshift-local-storage` project.
1.  Install and configure the LSO by using either the CLI or {{ product_title }} web console.
