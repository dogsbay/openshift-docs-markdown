# Viewing the current project {id="cli-using-cli-current-project_{{ context }}"}

Use the `oc project` command to view the current project. {._abstract}

**Procedure**

*   View the current project by running the following command:
    ```terminal
    $ oc project
    ```
    ```terminal title="Example output"
    Using project "my-project" on server "https://openshift.example.com:6443".
    ```
