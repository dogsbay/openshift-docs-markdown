# Run CNF latency test suite {id="run-cnf-latency-test-suite-intro_{{ context }}"}

The CNF latency test suite validates node performance by running hardware latency detection (hwlatdetect), cyclictest, and oslat tests. These tests measure system latency to verify that node tuning meets the requirements for CNF workloads.
