# Setting up automatic recurring upgrades {id="learning-getting-started-upgrading-recurring-updates_{{ context }}"}

To schedule your cluster to automatically receive new patch (z-stream) updates, you can set your cluster to upgrade on a recurring basis within {{ cluster_manager_url }}. {._abstract}

**Procedure**

1.  Log in to the {{ cluster_manager }}, and select the cluster you want to upgrade.
1.  Click the **Settings** tab.
1.  Under **Update Strategy**, click **Recurring updates**.
1.  Set the day and time for the upgrade to occur.
1.  Click **Save**.
