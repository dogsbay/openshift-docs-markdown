# Manage and revoke active user login tokens {id="manage-and-revoke-active-user-login-tokens-con_{{ context }}"}

You can list and inspect user-owned OAuth access tokens to see which sessions are currently active and what scopes they carry. Deleting a token immediately revokes the session, which lets you disconnect access that is no longer needed.
