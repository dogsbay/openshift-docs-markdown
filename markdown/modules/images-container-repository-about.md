# Image repository {id="images-container-repository-about_{{ context }}"}

An image repository is a collection of related container images and tags that identify them. You can use image repositories to organize and manage related container images in {{ product_title }}. {._abstract}

For example, the {{ product_title }} Jenkins images are in the following repository:

```text
docker.io/openshift/jenkins-2-centos7
```
