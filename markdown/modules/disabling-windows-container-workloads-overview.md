# Windows container workload removal {id="disabling-windows-container-workloads-overview_{{ context }}"}

You can disable the capability to run Windows container workloads by uninstalling the Windows Machine Config Operator (WMCO) and deleting the namespace that was added by default when you installed the WMCO. {._abstract}
