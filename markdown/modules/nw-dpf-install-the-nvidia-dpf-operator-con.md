# Installing the NVIDIA DPF Operator {id="nw-dpf-install-the-nvidia-dpf-operator_{{ context }}"}

You install the NVIDIA DPF Operator on your management cluster to enable DPU offloading for network workloads. Before installation, configure the required environment variables that define your cluster topology and DPU hardware parameters.
