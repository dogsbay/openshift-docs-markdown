# Manage an {{ product_title }} on Google Cloud cluster {id="osd-manage-a-red-hat-openshift-dedicated-on-google-cloud-cluster_{{ context }}"}

After you create an {{ product_title }} cluster on Google Cloud, configure an identity provider, grant administrator privileges, and give your users access to the cluster. You can then deploy an application, scale the cluster to meet demand, revoke access when it is no longer required, and clean up your resources when you no longer need the cluster.
