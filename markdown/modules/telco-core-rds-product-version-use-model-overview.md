# Telco core RDS use model overview {id="telco-core-rds-product-version-use-model-overview_{{ context }}"}

The Telco core reference design specification (RDS) describes a platform that supports large-scale telco applications including control plane and centralized data plane functions such as user plane functions (UPF). {._abstract}

These functions generally require scalability, complex networking support, resilient software-defined storage, and performance requirements that are less stringent than far-edge deployments such as RAN.
