# Change the configuration of compute machines by updating a compute machine set {id="change-the-configuration-of-compute-machines-by-updating-a-compute-machine-set-con_{{ context }}"}

You can change the configuration that a compute machine set applies to its machines by editing the machine set. Machines that already exist keep their current configuration, so they must be replaced before the change takes effect.
