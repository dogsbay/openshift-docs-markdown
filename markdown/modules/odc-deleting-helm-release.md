# Deleting a Helm release {id="odc-deleting-helm-release_{{ context }}"}

You can delete a Helm release from the **Topology** view in the **Developer** perspective of the web console. {._abstract}

**Procedure**

1.  In the **Topology** view, right-click the Helm release and select **Delete Helm Release**.
1.  In the confirmation prompt, enter the name of the release and click **Delete**.
