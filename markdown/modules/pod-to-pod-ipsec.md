# IPsec encryption for pod-to-pod traffic {id="pod-to-pod-ipsec_{{ context }}"}

IPsec encryption of pod-to-pod traffic covers which traffic is encrypted, which protocol is used, and how X.509 certificates are handled. {._abstract}

IPsec encryption between the cluster and external hosts requires manual configuration for your specific external network infrastructure.
