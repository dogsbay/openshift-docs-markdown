## New features and enhancements {id="compliance-operator-1-3-0-new-features-and-enhancements_{{ context }}"}

*   The Defense Information Systems Agency Security Technical Implementation Guide (DISA-STIG) for {{ product_title }} is now available from Compliance Operator 1.3.0. See [Supported compliance profiles](/security/compliance_operator/co-scans/compliance-operator-supported-profiles#compliance-supported-profiles_compliance-operator-supported-profiles) for additional information.
*   Compliance Operator 1.3.0 now supports {{ ibm_power_name }} and {{ ibm_z_name }} for NIST 800-53 Moderate-Impact Baseline for {{ product_title }} platform and node profiles.
