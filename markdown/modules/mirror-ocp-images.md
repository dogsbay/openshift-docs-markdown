# Mirroring {{ product_title }} images {id="about-disconnected-updates-mirroring_{{ context }}"}

You can mirror {{ product_title }} images to a local container image registry to provide your disconnected cluster with the resources necessary for targeted updates. 
A single container image registry is sufficient to host mirrored images for several clusters in the disconnected network. {._abstract}

For more information about mirroring images onto a repository in your disconnected cluster, see the "Mirroring {{ product_title }} images" section.
