# Verifying installation of {{ product_title }} clusters {id="rosa-verify-hcp-install_{{ context }}"}

If the {{ product_title }} cluster is in the installing state for over 30 minutes and has not become ready, ensure the AWS account environment is prepared for the required cluster configurations. If the AWS account environment is prepared for the required cluster configurations correctly, try to delete and re-create the cluster. If the problem persists, contact support. {._abstract}

**Procedure**

*   Verify the AWS account environment is prepared for the required cluster configurations.
*   If the AWS account environment is prepared correctly, try to delete and re-create the cluster.
*   If the problem persists, contact support.
