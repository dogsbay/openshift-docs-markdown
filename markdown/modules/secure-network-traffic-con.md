# Secure network traffic {id="secure-network-traffic-con_{{ context }}"}

You can manage network security in {{ product_title }} at several levels, from namespace and policy-based isolation between workloads to encryption of traffic as it enters, crosses, and leaves the cluster. Combining these controls lets you define which workloads can communicate and ensure that the traffic between them is protected in transit.
