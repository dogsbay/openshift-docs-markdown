# Creating a Jira issue {id="virt-creating-jira-issue_{{ context }}"}

To report a bug, use the Red Hat Issue Router (RHIR), which is available in the Customer Portal Labs. {._abstract}

**Procedure**

1.  Access the RHIR.
1.  In the list of all {{ VirtProductName }} components, find the component for which you want to report an issue.
1.  Click the **Report a bug** link of the component.
1.  On the **Create issue** page, fill out the form:
    1.  Complete the **Summary** and **Description** fields. In the **Description** field, include a detailed description of the issue.
    1.  Submit any collected troubleshooting information:
        1.  Add any textual troubleshooting information, such as command outputs, in the **Description** field.
        1.  Add troubleshooting files using the **Attachment** field.
1.  Click **Create** at the bottom of the page.
1.  Review the details of the bug you created.
