# Importing and working with images and image streams {id="images-imagestream-import-images-image-streams_{{ context }}"}

To bring container images into your {{ product_title }} cluster and manage their references, you can import images from external registries and organize them by using image streams. By using this process, you can maintain a centralized registry of container images for your applications. {._abstract}

The following sections describe how to import, and work with, image streams.
