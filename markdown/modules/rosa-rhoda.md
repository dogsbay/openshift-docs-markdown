# Red Hat OpenShift Database Access {id="rosa-rhoda_{{ context }}"}

{{ rhoda }} enables easy consumption of database-as-a-service (DBaaS) offerings from partners including MongoDB Atlas, Crunchy Bridge, CockroachDB, and Amazon Relational Database Service (RDS) directly from managed {{ product_title }} clusters. You can manage, monitor, and create cloud-hosted database instances for connecting to your applications.

{{ rhoda }} is a Service Preview release. A Service Preview release contains features that are early in development. Service Preview releases are not production ready and are not fully tested. Do not use {{ rhoda_short }} for production or business-critical workloads.
