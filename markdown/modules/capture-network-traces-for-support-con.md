# Capture network traces for support {id="capture-network-traces-for-support-con_{{ context }}"}

When a network problem is difficult to reproduce from logs alone, you capture live packet traces on the host network or on a pod interface. {{ product_title }} supports two collection methods, and Red&#160;Hat support uses these packet capture records to analyze traffic patterns and identify the root cause.
