# Additional permissions for individual users and groups {id="cloud-experts-entra-id-idp-additional-user-groups_{{ context }}"}

When you first log in, you might notice that you have very limited permissions. By default, {{ product_title }} only grants you the ability to create new projects, or namespaces, in the cluster. Other projects are restricted from view. {._abstract}

You must grant these additional abilities to individual users and groups.
