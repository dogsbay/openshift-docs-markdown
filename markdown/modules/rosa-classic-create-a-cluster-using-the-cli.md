# Create a cluster using the CLI {id="rosa-classic-create-a-cluster-using-the-cli_{{ context }}"}

As a cluster administrator, create a {{ product_title }} cluster from the command line by using the {{ rosa_cli_first }}. The {{ rosa_cli }} gives you precise control over cluster configuration for scripted and repeatable deployments. {._abstract}

Creating a cluster by using the {{ rosa_cli }} helps you to do the following:

*   Customize cluster settings, networking, and encryption during creation.
*   Integrate cluster provisioning into your existing command-line workflows.
