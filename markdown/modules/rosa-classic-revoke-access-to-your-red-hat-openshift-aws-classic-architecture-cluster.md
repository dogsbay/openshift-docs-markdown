# Revoke access to your Red Hat OpenShift AWS (Classic Architecture) cluster {id="rosa-classic-revoke-access-to-your-red-hat-openshift-aws-classic-architecture-cluster_{{ context }}"}

An identity provider (IDP) controls access to a {{ product_title }} cluster. To revoke access of a user to a cluster, you must configure that within the IDP that was set up for authentication.
