# Use developer workflows in the console {id="use-developer-workflows-in-the-console-con_{{ context }}"}

The **Developer** perspective of the {{ product_title }} web console gives you a visual path through the application lifecycle, from deploying an application to monitoring its metrics in the **Topology** view. {._abstract}

You can deploy an application from a sample, a Git repository, an existing container image, or the developer catalog, then view its composition, edit it, and delete it when you are done.
