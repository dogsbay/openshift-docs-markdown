# Use developer workflows in the console {id="use-developer-workflows-in-the-console-con_{{ context }}"}

The **Developer** perspective of the {{ product_title }} web console gives you a visual path through the application lifecycle. You can deploy an application from a sample, a Git repository, an existing container image, or the developer catalog, then view its composition in the **Topology** view, edit it, monitor its metrics, and delete it when you are done.
