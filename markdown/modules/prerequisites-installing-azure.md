# Prerequisites for installing a cluster on {{ azure_short }} {id="prerequisites-installing-azure_{{ context }}"}

Before you install an {{ product_title }} cluster on {{ azure_short }}, ensure that you have selected a cluster installation method and configured an {{ azure_short }} account to host the cluster and determine the tested and validated region to deploy the cluster to. {._abstract}

If you use a firewall, you must configure it to allow the sites that your cluster requires access to.
