# OpenID Connect Overview {id="rosa-classic-openid-connect-overview_{{ context }}"}

OpenID Connect (OIDC) uses Security Token Service (STS) to allow clients to provide a web identity token to gain access to multiple services. {{ product_title }} clusters use STS and OIDC to grant the in-cluster operators access to necessary AWS resources.
