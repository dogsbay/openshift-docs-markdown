# Configuring DPF deployment resources {id="nw-dpf-configure-dpf-deployment-resources_{{ context }}"}

You configure the NVIDIA DPF Operator deployment resources by creating the SR-IOV network configuration, DPU flavor, boot firmware image, and DPU deployment custom resources. These resources define the hardware profile and deployment parameters for your DPU nodes.
