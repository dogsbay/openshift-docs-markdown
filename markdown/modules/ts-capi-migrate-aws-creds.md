# Migrating {{ aws_short }} cloud credentials {id="ts-capi-migrate-aws-creds_{{ context }}"}

The two-way synchronization controller that maintains changes between Machine API and Cluster API resources does not automatically copy {{ aws_first }} credential secrets. 
For more information, see the Red&#160;Hat Knowledgebase article [Migrate AWS cloud credentials between Machine API and Cluster API](https://access.redhat.com/articles/7116313).
