# Choose registry storage for your platform {id="choose-registry-storage-for-your-platform-con_{{ context }}"}

The integrated image registry requires storage, and the default differs by platform: cloud installations provision object storage automatically, while bare-metal, vSphere, and Nutanix installations leave the registry removed until you configure storage yourself. Select a backend before you configure the registry.
