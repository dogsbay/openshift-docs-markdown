# Troubleshoot {{ product_title }} access and deployment issues {id="rosa-troubleshoot-access-and-deployment-issues_{{ context }}"}

Cluster administrators need to diagnose and resolve access management and deployment problems so that they can authenticate to the {{ product_title }} service and provision their clusters successfully. {._abstract}

Troubleshooting access and deployment helps you:

*   **Restore access**: Identify expired credentials or incorrectly configured IAM roles to resolve problems with authentication and permissions.
*   **Unblock cluster creation**: Use reported deployment errors to identify unmet requirements that are necessary for provisioning to proceed.
