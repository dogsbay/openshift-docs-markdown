# Updating hardware on nodes running in vSphere {id="updating-clusters-overview-vsphere-updating-hardware_{{ context }}"}

Ensure that your nodes running in vSphere are running on a supported virtual hardware version. {._abstract}

[Updating hardware on vSphere](/updating/updating_a_cluster/updating-hardware-on-nodes-running-on-vsphere#updating-hardware-on-nodes-running-on-vsphere): You must ensure that your nodes running in vSphere are running on the hardware version supported by {{ product_title }}. Currently, hardware version 15 or later is supported for vSphere virtual machines in a cluster. For more information, see the following:

*   [Updating virtual hardware on vSphere](/updating/updating_a_cluster/updating-hardware-on-nodes-running-on-vsphere#updating-virtual-hardware-on-vsphere_updating-hardware-on-nodes-running-in-vsphere)
*   [Scheduling an update for virtual hardware on vSphere](/updating/updating_a_cluster/updating-hardware-on-nodes-running-on-vsphere#scheduling-virtual-hardware-update-on-vsphere_updating-hardware-on-nodes-running-in-vsphere)


:::important

Version {{ product_version }} of {{ product_title }} requires VMware virtual hardware version 15 or later.

:::
