# Understanding templates {id="templates-overview_{{ context }}"}

You can use templates to describe reusable, parameterized object sets that {{ product_title }} processes into resources such as `Service` and `DeploymentConfig` objects. Templates help you deploy the same application structure consistently from the web console or CLI. {._abstract}

A template can be processed to create anything you have permission to create within a project. A template can also define a set of labels to apply to every object defined in the template.
