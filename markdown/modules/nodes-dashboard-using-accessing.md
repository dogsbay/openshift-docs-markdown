# Accessing the node metrics dashboard {id="nodes-dashboard-using-accessing_{{ context }}"}

You can access the node metrics dashboard from the **Administrator** perspective of the {{ product_title }} web console. {._abstract}

**Procedure**

1.  Expand the **Observe** menu option and select **Dashboards**.
1.  Under the **Dashboard** filter, select **Node cluster**.

    :::note

    If no data appears in the visualizations under the **Critical** category, no critical anomalies were detected. The dashboard is working as intended.
    
    :::
