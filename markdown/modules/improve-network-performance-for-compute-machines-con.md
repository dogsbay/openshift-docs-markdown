# Improve network performance for compute machines {id="improve-network-performance-for-compute-machines-con_{{ context }}"}

Several machine settings affect how fast a compute machine moves traffic. You can shorten the network path between machines, give a machine a more direct path to the switch, or give it more than one interface so that different kinds of traffic do not share a link.
