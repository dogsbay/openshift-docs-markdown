# Security Profiles Operator release notes {id="security-profiles-operator-release-notes_{{ context }}"}

Review new features, enhancements, fixed issues, and known issues for the Security Profiles Operator. The Security Profiles Operator provides a way to define secure computing (seccomp) and SELinux profiles as custom resources, synchronizing profiles to every node in a given namespace.
