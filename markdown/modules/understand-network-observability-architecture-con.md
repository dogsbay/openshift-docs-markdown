# Understand network observability architecture {id="understand-network-observability-architecture-con_{{ context }}"}

The Network Observability Operator deploys a monitoring pipeline that collects and enriches the network traffic flows generated by the eBPF agent. Understanding how its components collect, enrich, and store those flows helps you plan a deployment that fits your cluster.
