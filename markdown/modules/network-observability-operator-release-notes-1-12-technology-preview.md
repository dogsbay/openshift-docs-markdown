# Network Observability Operator 1.12 Technology Preview features {id="network-observability-operator-release-notes-1-12-technology-preview_{{ context }}"}

The Network Observability Operator is included by default as a Technology Preview feature in 1.12 and {{ product_title }} 4.22. You can explore network traffic visualization and monitoring capabilities without performing a separate installation. {._abstract}

To use this Technology Preview feature, you must enable the `NetworkObservabilityInstall` feature gate through a manifest file during cluster installation.
