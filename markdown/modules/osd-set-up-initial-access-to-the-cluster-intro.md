# Set up initial access to the cluster {id="osd-set-up-initial-access-to-the-cluster-intro_{{ context }}"}

As a cluster administrator, set up initial access to your {{ product_title }} cluster. Users can sign in and start to work with the cluster after you configure an identity provider and grant administrator access. {._abstract}

Setting up initial access helps you to do the following:

*   Enable your users to authenticate to the cluster through your chosen identity provider.
*   Grant the appropriate level of administrator access to the right users.
*   Control who can access the cluster and what they can do.
