# Requirements for using {{ cluster_manager }} {id="rosa-ocm-requirements_{{ context }}"}

The following configuration details are required only if you use {{ cluster_manager_url }} to manage your clusters. If you use the CLI tools exclusively, then you can disregard these requirements.

To use {{ cluster_manager }}, you must link the roles in your Red&#160;Hat user organization and your Red&#160;Hat account to your AWS account. This linking concept is also known as account association.
