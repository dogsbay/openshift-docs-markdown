# Deleting a {{ product_title }} cluster using the UI {id="cloud-experts-getting-started-deleting-ui_{{ context }}"}

You can delete your cluster by using {{ cluster_manager }}. {._abstract}

**Procedure**

1.  Log in to the {{ cluster_manager_url }}, and locate the cluster you want to delete.
1.  Click the three dots to the right of the cluster.
    ![cloud-experts-getting-started-deleting1](/_assets/images/cloud-experts-getting-started-deleting1.png)
1.  In the dropdown menu, click **Delete cluster**.
    ![cloud-experts-getting-started-deleting2](/_assets/images/cloud-experts-getting-started-deleting2.png)
1.  Enter the name of the cluster to confirm deletion, and click **Delete**.
