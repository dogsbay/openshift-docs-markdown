## Limited support {id="_limited_support"}
If a {{ product_title }} cluster is not upgraded before the "end of life" date, the cluster continues to operate in a limited support status. The SLA for that cluster will no longer be applicable, but you can still get support for that cluster.

Additional support resources:

*   [Red&#160;Hat Support](https://access.redhat.com/)
*   [AWS Support](https://aws.amazon.com/premiumsupport/)

    AWS support customers must have a valid AWS support contract.
