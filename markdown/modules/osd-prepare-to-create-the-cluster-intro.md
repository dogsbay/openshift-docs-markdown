# Prepare to create the cluster {id="osd-prepare-to-create-the-cluster-intro_{{ context }}"}

As a cluster administrator, prepare your environment before you create an {{ product_title }} cluster on Amazon Web Services (AWS). When you review the requirements and configure your AWS account in advance, your account and network are ready for the cluster creation workflow. {._abstract}

Preparing before you create a cluster helps you to do the following:

*   Confirm that your AWS account meets the customer, resource, and service requirements.
*   Configure your AWS account and firewall for the cluster.
*   Understand the AWS resources that {{ product_title }} provisions on your behalf.
