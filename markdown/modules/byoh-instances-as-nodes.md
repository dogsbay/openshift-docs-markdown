# BYOH Windows instances {id="byoh-instances-as-nodes_{{ context }}"}

You can create Bring-Your-Own-Host (BYOH) Windows instances to bring existing Windows Server virtual machines (VMs) into {{ product_title }}. By using BYOH Windows instances, you can mitigate major disruptions if a Windows server goes offline.
