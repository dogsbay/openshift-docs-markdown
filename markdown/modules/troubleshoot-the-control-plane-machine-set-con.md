# Troubleshoot the control plane machine set {id="troubleshoot-the-control-plane-machine-set-con_{{ context }}"}

A control plane machine set cannot manage your machines if its state is wrong, if a required provider parameter is missing, or if an upgraded cluster carries a configuration it does not accept. Check the state first, then apply the fix for your platform.
