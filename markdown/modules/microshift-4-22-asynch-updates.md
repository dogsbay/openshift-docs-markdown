# Asynchronous updates {id="microshift-4-22-asynch-updates_{{ context }}"}

Security, bug fix, and enhancement updates for {{ microshift_short }} {{ product_version }} are released asynchronously through the Red&#160;Hat Network. All {{ microshift_short }} {{ product_version }} updates are [available on the Red&#160;Hat Customer Portal](https://access.redhat.com/downloads/content/290/). For more information about asynchronous updates, read the [{{ microshift_short }} Life Cycle](https://access.redhat.com/product-life-cycles?product=Red%20Hat%20build%20of%20Microshift,Red%20Hat%20Device%20Edge). {._abstract}

Red&#160;Hat Customer Portal users can enable update notifications in the account settings for Red&#160;Hat Subscription Management (RHSM). When notifications are enabled, you are notified through email whenever new updates relevant to your registered systems are released.


:::note

Red&#160;Hat Customer Portal user accounts must have systems registered and consuming {{ microshift_short }} entitlements for {{ microshift_short }} update notification emails to generate.

:::
