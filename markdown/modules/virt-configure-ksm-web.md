# Configuring KSM activation by using the web console {id="virt-configure-ksm-web_{{ context }}"}

You can allow {{ VirtProductName }} to activate kernel samepage merging (KSM) on all nodes in your cluster by using the {{ product_title }} web console. {._abstract}

**Procedure**

1.  From the side menu, click **Virtualization** → **Settings**.
1.  Select the **Cluster** tab.
1.  Expand **Resource management**.
1.  Enable or disable the feature for all nodes using the **Kernel Samepage Merging (KSM)** toggle button.
