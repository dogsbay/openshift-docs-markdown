# Add nodes to an on-premise cluster {id="add-nodes-to-an-on-premise-cluster-con_{{ context }}"}

To run more application workloads on-premise and to maintain high availability, you can expand your {{ product_title }} cluster with additional compute nodes. You can add worker nodes by using the {{ oc_first }} to generate an ISO image, or by creating {{ op_system }} machines directly on bare metal or VMware vSphere infrastructure and then approving their certificate signing requests.
