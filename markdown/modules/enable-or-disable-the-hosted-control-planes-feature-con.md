# Enable or disable the hosted control planes feature {id="enable-or-disable-the-hosted-control-planes-feature-con_{{ context }}"}

Before you can create hosted clusters, the hosted control planes feature must be enabled on the management cluster. You enable it by installing the HyperShift Operator, and you disable it by uninstalling the Operator and turning the feature off.
