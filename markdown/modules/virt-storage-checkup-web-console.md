# Running a storage checkup by using the web console {id="virt-storage-checkup-web-console_{{ context }}"}

You can run a storage checkup to validate that storage is working correctly for virtual machines. {._abstract}

**Procedure**

1.  Navigate to **Virtualization** -> **Checkups** in the web console.
1.  Click the **Storage** tab.
1.  Click **Install permissions**.
1.  Click **Run checkup**.
1.  Enter a name for the checkup in the **Name** field.
1.  Enter a timeout value for the checkup in the **Timeout (minutes)** fields.
1.  Click **Run**.

**Result**

You can view the status of the storage checkup in the **Checkups** list on the **Storage** tab. Click on the name of the checkup for more details.
