# Create multi-architecture compute clusters on bare metal, {{ ibm_power_title }}, or {{ ibm_z_title }} {id="create-multi-architecture-compute-clusters-on-bare-metal-ibm-power-or-ibm-z-con_{{ context }}"}

You can add compute nodes of a different architecture to an on-premise cluster by creating ISO or PXE boot media for that architecture. After the nodes boot, approve their certificate signing requests so that they join the cluster.
