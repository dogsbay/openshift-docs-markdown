# Sign up for FedRAMP access to create a {{ product_title }} cluster in GovCloud {id="rosa-hcp-sign-up-for-fedramp-access-to-create-a-red-hat-openshift-service-on-aws-cluster-in-govcloud_{{ context }}"}

Sign up for a Red&#160;Hat FedRAMP account to access {{ product_title }} in AWS GovCloud. FedRAMP-compliant {{ product_title }} clusters enable federal agencies and their supporting contractors to run containerized workloads in authorized government cloud environments. {._abstract}


:::note

This service is available to the following organizations:

*   Federal and government agencies
*   Commercial organizations that support or are bidding on a government contract
*   Federal Information Security Modernization Act (FISMA) research and development universities that support or are bidding on a government contract

:::
