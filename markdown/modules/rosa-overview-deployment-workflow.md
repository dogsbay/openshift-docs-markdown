# Overview of the {{ product_title }} deployment workflow {id="rosa-overview-of-the-deployment-workflow_{{ context }}"}

You can follow the workflow stages outlined in this section to set up and access a {{ product_title }} cluster. {._abstract}

1.  [Perform the AWS prerequisites](https://docs.redhat.com/en/documentation/red_hat_openshift_service_on_aws_classic_architecture/4/html-single/install_rosa_classic_clusters/index#prerequisites). To deploy a {{ product_title }} cluster, your AWS account must meet the prerequisite requirements.
1.  [Review the required AWS service quotas](https://docs.redhat.com/en/documentation/red_hat_openshift_service_on_aws_classic_architecture/4/html-single/install_rosa_classic_clusters/index#rosa-required-aws-service-quotas). To prepare for your cluster deployment, review the AWS service quotas that are required to run a {{ product_title }} cluster.
1.  [Configure your AWS account](https://docs.redhat.com/en/documentation/red_hat_openshift_service_on_aws_classic_architecture/4/html-single/install_rosa_classic_clusters/index#rosa-config-aws-account). Before you create a {{ product_title }} cluster, you must enable {{ product_title }} in your AWS account, install and configure the AWS CLI (`aws`) tool, and verify the AWS CLI tool configuration.
1.  [Install the {{ product_title }} and OpenShift CLI tools and verify the AWS servce quotas](https://docs.redhat.com/en/documentation/red_hat_openshift_service_on_aws_classic_architecture/4/html-single/install_rosa_classic_clusters/index#rosa-installing-cli). Install and configure the {{ rosa_cli_first }} and the {{ oc_first }}. You can verify if the required AWS resource quotas are available by using the {{ rosa_cli }}.
1.  [Create a {{ product_title }} cluster](https://docs.redhat.com/en/documentation/red_hat_openshift_service_on_aws_classic_architecture/4/html-single/install_rosa_classic_clusters/index#rosa-creating-cluster) or [Create a ROSA cluster using AWS PrivateLink](https://docs.redhat.com/en/documentation/red_hat_openshift_service_on_aws_classic_architecture/4/html-single/install_rosa_classic_clusters/index#rosa-aws-privatelink-creating-cluster). Use the ROSA CLI (`rosa`) to create a cluster. You can optionally create a ROSA cluster with AWS PrivateLink.
1.  [Access a cluster](https://docs.redhat.com/en/documentation/red_hat_openshift_service_on_aws_classic_architecture/4/html-single/install_rosa_classic_clusters/index#rosa-sts-accessing-cluster). You can configure an identity provider and grant cluster administrator privileges to the identity provider users as required. You can also access a newly deployed cluster quickly by configuring a `cluster-admin` user.
1.  [Revoke access to a ROSA cluster for a user](https://docs.redhat.com/en/documentation/red_hat_openshift_service_on_aws_classic_architecture/4/html-single/install_rosa_classic_clusters/index#rosa-deleting-access-cluster). You can revoke access to a {{ product_title }} cluster from a user by using the {{ rosa_cli }} or the web console.
1.  [Delete a ROSA cluster](https://docs.redhat.com/en/documentation/red_hat_openshift_service_on_aws_classic_architecture/4/html-single/install_rosa_classic_clusters/index#rosa-deleting-cluster). You can delete a {{ product_title }} cluster by using the {{ rosa_cli }}.
