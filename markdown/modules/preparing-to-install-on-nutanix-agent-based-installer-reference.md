# Agent-based Installer {id="preparing-to-install-on-nutanix-agent-based-installer-reference_{{ context }}"}

You can install an {{ product_title }} cluster on Nutanix by using the Agent-based Installer.
The Agent-based Installer can be used to install a three-node cluster, which is a smaller, more resource efficient cluster for testing, development, and production.
