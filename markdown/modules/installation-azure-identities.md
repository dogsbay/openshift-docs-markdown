# Supported identities to access {{ azure_short }} resources {id="installation-azure-identities_{{ context }}"}

An {{ product_title }} cluster requires an {{ azure_short }} identity to create and manage {{ azure_short }} resources. You need a service principal, a system-assigned managed identity, or a user-assigned managed identity to complete the installation. {._abstract}

*   A service principal
*   A system-assigned managed identity
*   A user-assigned managed identity

For more information on Azure identities, see "Managed identity types".
