# Protect virtual machine data {id="oadp-protect-virtual-machine-data-intro_{{ context }}"}

Use the OpenShift API for Data Protection (OADP) to back up, restore, and recover data for virtual machines running on {{ VirtProductName }}. OADP provides VM-specific features including single VM backup and restore, VM File Restore (VMFR), and VM Data Protection (VMDP).
