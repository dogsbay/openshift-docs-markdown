# Identifying why VM nodes are not joining the cluster {id="hcp-ts-vm-nodes_{{ context }}"}

If a hosted control plane is not coming fully online because the virtual machine (VM) nodes are not correctly joining the cluster, access the VM console logs. {._abstract}

**Procedure**

*   To access the VM console logs, complete the steps in "How to get serial console logs for VMs part of OpenShift Virtualization Hosted Control Plane clusters".
