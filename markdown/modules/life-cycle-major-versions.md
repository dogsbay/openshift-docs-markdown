# Major versions (X.y.z) {id="rosa-major-versions_{{ context }}"}

Major versions of {{ product_title }}, for example version 4, are supported for one year following the release of a later major version or the retirement of the product. {._abstract}

For example, if version 5 was made available on {{ product_title }} on January 1, version 4 would be allowed to continue running on managed clusters for 12 months, until December 31. After this time, clusters would need to be upgraded or migrated to version 5.
