# Design and deploy user-defined network segments {id="design-and-deploy-user-defined-network-segments-con_{{ context }}"}

User-defined networks (UDNs) extend OVN-Kubernetes to enable custom layer 2 and layer 3 network segments with default isolation. UDNs provide enhanced network flexibility, security, and segmentation capabilities for multi-tenant deployments and custom network architectures.
