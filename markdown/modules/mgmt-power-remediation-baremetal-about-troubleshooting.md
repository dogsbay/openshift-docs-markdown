# Troubleshooting issues with power-based remediation {id="mgmt-power-remediation-baremetal-about-troubleshooting_{{ context }}"}

To troubleshoot issues you are having with power-based remediation, check the connection to the Baseboard Management Controller (BMC). {._abstract}

**Procedure**

*   Verify the following conditions:
    *   You have access to the BMC.
    *   The BMC is connected to the control plane node that is responsible for running the remediation task.
