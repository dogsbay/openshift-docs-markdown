# Activate {{ product_title }} cluster and link your AWS account {id="rosa-hcp-activate-red-hat-openshift-services-on-aws-cluster-and-link-your-aws-account_{{ context }}"}

Before deploying your first cluster, activate your {{ product_title }} subscription, link your AWS and Red&#160;Hat accounts, and select the correct billing account. {._abstract}


:::important

If you have received a private offer for the product, make sure to proceed according to the instructions provided with the private offer before following this tutorial. The private offer is designed either for a case when the product is already activated, which replaces an active subscription, or for first time activations.

:::
