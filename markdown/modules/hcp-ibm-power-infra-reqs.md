# {{ ibm_power_title }} infrastructure requirements {id="hcp-ibm-power-infra-reqs_{{ context }}"}

The Agent platform does not create any infrastructure, but requires resources for infrastructure. {._abstract}

*   Agents: An _Agent_ represents a host that boots with a Discovery image and that you can provision as an {{ product_title }} node.
*   DNS: The API and Ingress endpoints must be routable.
