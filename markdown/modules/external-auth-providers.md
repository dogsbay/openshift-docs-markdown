# Direct authentication identity providers {id="external-auth-providers_{{ context }}"}

Direct authentication has been tested with multiple OpenID Connect (OIDC) identity providers to help you verify compatibility before configuring your cluster. {._abstract}

The following identity providers have been tested:

*   Active Directory Federation Services for Windows Server
*   GitLab
*   Google
*   Keycloak
*   Microsoft Entra ID
*   Okta
*   Ping Identity
*   Red Hat Single Sign-On


:::note

Red&#160;Hat does not test all factors associated with third-party identity provider functionality.

:::
