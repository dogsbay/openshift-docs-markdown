# Application and cluster configuration policy changes {id="core-cluster-upgrade-scenario-policy-changes_{{ context }}"}

In addition to {{ product_title }} and OLM Operator update policies, review and prepare policies for application and cluster configuration changes that the update might require. {._abstract}

This can include changes to user policies, security context constraints (SCCs), or version-specific configuration for your cluster.

For further policy configuration, see the {{ rh_rhacm_first }} documentation.
