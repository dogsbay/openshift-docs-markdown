# Machine API Operator {id="machine-api-operator_{{ context }}"}

The Machine API Operator manages the lifecycle of specific purpose custom resource definitions (CRD), controllers, and role based access control (RBAC) objects that extend the Kubernetes API and declare the desired state of machines in a cluster. {._abstract}

## CRDs {id="_crds"}

*   `MachineSet`
*   `Machine`
*   `MachineHealthCheck`
