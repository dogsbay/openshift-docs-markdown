# Isolate compute machines from other tenants {id="isolate-compute-machines-from-other-tenants-con_{{ context }}"}

You can deploy compute machines onto hardware that your account does not share with other customers. Dedicated Instances isolate machines at the host hardware level. Dedicated Hosts give you a physical server that you control and can target by host ID.
