# Preparing the {{ oci }} image {id="c3-assisted-installer-preparing-image_{{ context }}"}

Generate the {{ product_title }} ISO image in the {{ ai_full }} on the Red&#160;Hat portal. Then, convert the image to an {{ oci_edge_no_rt }} compatible image and upload it to the **Custom Images** page of your {{ oci_edge_no_rt }} environment. {._abstract}

You can generate, convert and upload the image on your laptop and not on the bastion server or within environments such as Oracle Solution Center.
