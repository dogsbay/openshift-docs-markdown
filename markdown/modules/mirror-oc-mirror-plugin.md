# Mirroring resources using the oc-mirror plugin {id="mirroring-ocp-resources-ocmirror_{{ context }}"}

You can use the oc-mirror OpenShift CLI (`oc`) plugin to mirror images to a mirror registry in your fully or partially disconnected environments. You must run oc-mirror from a system with internet connectivity to download the required images from the official Red&#160;Hat registries. {._abstract}

For more information, see "Mirroring images for a disconnected installation by using the oc-mirror plugin v2".
