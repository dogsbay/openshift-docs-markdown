# Scan and remediate compliance issues by using the Compliance Operator {id="scan-and-remediate-compliance-issues-by-using-the-compliance-operator-con_{{ context }}"}

The Compliance Operator audits cluster nodes and platform configuration against industry benchmarks and reports the results as custom resources. After you install the Operator, you can schedule scans, tailor the profiles they apply, and let the Operator remediate the misconfigurations it finds.
