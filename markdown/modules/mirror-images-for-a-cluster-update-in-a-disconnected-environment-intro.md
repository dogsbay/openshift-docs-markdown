# Mirror images for a cluster update in a disconnected environment {id="mirror-images-for-a-cluster-update-in-a-disconnected-environment-intro_{{ context }}"}

You must mirror container images onto a mirror registry to update a cluster in a disconnected environment. In connected environments, mirroring images ensures that your clusters run only approved container images that meet your organizational controls for external content. {._abstract}


:::note

Your mirror registry must be running at all times while the cluster is running.

:::


The following steps outline the high-level workflow about mirroring images to a mirror registry:

1.  Install the OpenShift CLI (`oc`) on all devices that you use to retrieve and push release images.
1.  Download the registry pull secret and add it to your cluster.
1.  Choose the appropriate method to mirror your images:
    1.  Method 1: If you use the oc-mirror OpenShift CLI (`oc`) plugin:
        1.  Install the oc-mirror plugin on all devices that you use to retrieve and push release images.
        1.  Create an image set configuration file for the plugin to use when determining which release images to mirror. You can edit this configuration file later to change which release images that the plugin mirrors.
        1.  Mirror your targeted release images directly to a mirror registry, or to removable media and then to a mirror registry.
        1.  Configure your cluster to use the resources generated by the oc-mirror plugin.
        1.  Repeat these steps as needed to update your mirror registry.
    1.  Method 2: If you use the `oc adm release mirror` command:
        1.  Set environment variables that correspond to your environment and the release images you want to mirror.
        1.  Mirror your targeted release images directly to a mirror registry, or to removable media and then to a mirror registry.
        1.  Repeat these steps as needed to update your mirror registry.

The `oc-mirror` plugin offers the following advantages over the `oc adm release mirror` command:

*   Mirrors content other than container images.
*   Simplifies updating images in the registry after the initial mirror.
*   Automates mirroring the release payload from Quay and builds the latest graph data image for the OpenShift Update Service in disconnected environments.
