# Control network policies and access for the Network Observability Operator {id="control-network-policies-and-access-for-network-observability-operator-con_{{ context }}"}

You can create a network policy for the `netobserv` namespace to secure inbound and outbound access to the Network Observability Operator. You can also grant the permissions the Operator needs to read secrets and to run in a custom namespace.
