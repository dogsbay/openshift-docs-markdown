# Manage application passwords and cloud provider credentials {id="manage-application-passwords-and-cloud-provider-credentials-con_{{ context }}"}

Secrets management tools automate the lifecycle of sensitive data such as passwords, private files, certificates, and cloud provider credentials by providing a central system to control and monitor access. Using them limits the uncontrolled spread of secrets and keeps credentials out of source code and container images.
