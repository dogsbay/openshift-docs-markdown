# Understand terminology and definitions {id="understand-terminology-and-definitions-con_{{ context }}"}

{{ product_title }} documentation uses a shared vocabulary that spans architecture, installation, nodes, storage, authentication, monitoring, the image registry, updates, and disconnected environments. Terms carry precise meanings that are often narrower than their general Kubernetes or industry usage, and the same word can mean different things in different feature areas. {._abstract}

The glossaries that follow define the common terms for each feature area, together with the terminology that governs API compatibility. Read the glossary for the area you are working in first, then consult the others when a procedure or reference crosses feature boundaries.
