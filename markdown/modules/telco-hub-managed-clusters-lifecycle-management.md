# Managed cluster lifecycle management {id="telco-hub-managed-clusters-lifecycle-management_{{ context }}"}

To provision and manage sites at the far edge of the network, use {{ ztp }} in a hub-and-spoke architecture, where a single hub cluster manages many managed clusters. {._abstract}

Lifecycle management for spoke clusters can be divided into two different stages: cluster deployment, including {{ product_title }} installation, and cluster configuration.
