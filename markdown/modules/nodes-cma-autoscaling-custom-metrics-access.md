# Accessing performance metrics {id="nodes-cma-autoscaling-custom-metrics-access_{{ context }}"}

You can access the metrics and run queries by using the {{ product_title }} web console.

**Procedure**

1.  Select the **Administrator** perspective in the {{ product_title }} web console.
1.  Select **Observe** → **Metrics**.
1.  To create a custom query, add your PromQL query to the **Expression** field.
1.  To add multiple queries, select **Add Query**.
