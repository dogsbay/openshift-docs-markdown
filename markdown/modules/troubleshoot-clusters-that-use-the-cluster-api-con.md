# Troubleshoot clusters that use the Cluster API {id="troubleshoot-clusters-that-use-the-cluster-api-con_{{ context }}"}

On a cluster that supports changing the authoritative API, the synchronization controller keeps a matching resource for the API that is not authoritative. The differences between the two APIs produce symptoms you can learn to recognize.
