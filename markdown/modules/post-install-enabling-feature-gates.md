# Enabling Technology Preview features using FeatureGates {id="post-install-tp-tasks_{{ context }}"}

Enable Technology Preview features cluster-wide by editing the `FeatureGate` custom resource. {._abstract}

You can turn on a subset of the current Technology Preview features on for all nodes in the cluster by editing the `FeatureGate` custom resource (CR).
