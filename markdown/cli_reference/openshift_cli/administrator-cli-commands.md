# OpenShift CLI administrator command reference {id="cli-administrator-commands"}
{%- set context = "cli-administrator-commands" %}

To learn more about the {{ oc_first }} administrator commands, review their descriptions and example commands. You must have `cluster-admin` or equivalent permissions to use these commands. {._abstract}

For developer commands, see the "OpenShift CLI developer command reference".

Run `oc adm -h` to list all administrator commands or run `oc <command> --help` to get additional details for a specific command.
